# Glossaire FR → EN — axelremillat.com

Commun aux trois lots (socle + pages, démos agent/automatisations, VEGA/pipeline/preuves).
**Complétez-le** dès que vous fixez un terme : une même notion porte le même mot partout.

## Règles d'écriture

- Anglais écrit pour un lecteur natif, **jamais traduit mot à mot**. Anglais international, **orthographe US** (*optimize*, *color*, *center*).
- Même ton que le français : direct, concret, phrases courtes. Mêmes arguments, mêmes chiffres.
- Tutoiement/vouvoiement : l'anglais dit simplement *you*.
- Montants : symbole avant, virgule des milliers — **€1,750**, **€290/month**. HT → *excl. VAT* ; TTC → *incl. VAT*.
- Dates : *October 13, 2026* ; heures : *9:30 AM* (Paris time si utile).
- Les noms de produits ne se traduisent pas : **VEGA**, **ORION**, **n8n**, **Codeur**, **Upwork**, **Malt**.

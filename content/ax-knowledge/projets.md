# Projets d'Axel Remillat

## RISE — Plateforme de mobilité internationale étudiante
Co-fondateur et Lead Tech depuis octobre 2024.
Plateforme qui facilite la mobilité internationale des étudiants : recherche de logement, communauté, ressources administratives.
Stack : React, Firebase, TypeScript.
Résultats : 3 concours remportés — Concours IONIS 2025 (2ème prix, 3000€), Galets du Rhône 2025 et Concours ESME (1er prix, 1500€). Association officielle, bêta en déploiement.

## A.X — CV RAG Interactif (ce projet)
IA conversationnelle pour présenter le profil d'Axel.
Stack : Next.js, OpenAI API (gpt-4o-mini + text-embedding-3-large), Supabase pgvector.
Retrieval Augmented Generation : les questions sont transformées en embeddings, comparées vectoriellement à une base de connaissances, puis une réponse est générée avec le contexte récupéré.

## Automatisation IA — Agents N8N
Conception d'agents IA pour automatisation de tâches métiers depuis septembre 2025.
Stack : N8N, OpenAI API, Webhooks, Make, Google Cloud.
Cas d'usage : automatisation de workflows marketing, traitement de données, agents de classification.

## Planète qui Chante — Jeu 3D portfolio
Jeu 3D interactif accessible depuis le portfolio. Un personnage explore une planète (référence au Petit Prince) avec des portails vers les projets.
Stack : Next.js, React Three Fiber, Three.js, TypeScript.
Contient : système de quêtes, NPC interactifs (renard, mouton), effets sonores, animations procédurales.

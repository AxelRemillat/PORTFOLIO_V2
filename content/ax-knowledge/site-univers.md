# Le site — Univers

Le site est construit autour d'un univers espace inspiré du Petit Prince de Saint-Exupéry — une œuvre française universelle qu'Axel adore, liée à un souvenir d'enfance : il a joué le renard dans une adaptation théâtrale. On y trouve : une page d'accueil avec fond étoilé et astéroïdes 3D ; un mini-jeu 3D où l'on déplace un petit robot sur une planète flottante façon Petit Prince (déplacement ZQSD/flèches, saut, clic pour se déplacer) avec 4 portails colorés qui téléportent vers les projets ; une page projets avec des modèles 3D animés pour chaque projet (drone pour le CV RAG, avion pour RISE, satellite pour SEACO, robot pour N8N) ; et la page VEGA. Le parti pris : un portfolio qui se visite comme un petit monde, où chaque projet se teste au lieu de se lire. Style visuel : premium, futuriste, sobre — le contenu d'abord.

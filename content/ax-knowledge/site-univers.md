# Le site — Univers

Le site est construit autour d'un univers espace inspiré du Petit Prince de Saint-Exupéry — une œuvre française universelle qu'Axel adore, liée à un souvenir d'enfance : il a joué le renard dans une adaptation théâtrale. Cet univers se retrouve dès l'accueil, avec sa vidéo hero façon Petit Prince (personnage et planète dessinés dans l'espace), et sur la page /projets, où chaque preuve a sa card avec un modèle 3D animé : le robot pour VEGA, le drone pour les automatisations N8N, le satellite pour l'infrastructure self-hosted. Le parti pris : un portfolio qui se teste au lieu de se lire — chaque affirmation est vérifiable sur pièce. Style visuel : premium, futuriste, sobre — le contenu d'abord.
